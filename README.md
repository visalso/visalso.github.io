# Personal website

Visal's personal academic website built with Jekyll and published through GitHub Actions, using ChatGPT's assistance.

## Where to edit

| File | What it controls |
| --- | --- |
| `index.html` | Homepage introduction and background paragraph |
| `research.html` | Research descriptions and links |
| `_data/publications.yml` | Publication details and selected papers |
| `_data/news.yml` | News, talks, and updates |
| `cv.html` | Career summary and document links |
| `_config.yml` | Contact details, navigation, site settings, and CV date |
| `assets/css/site.css` | Colors, typography, spacing, and responsive styling |

`404.html` handles missing pages. `research-highlights.html` redirects the old `/Research Highlights/` address to the research page.
